01 / 认识一下

不是所有文件，
都需要去云端旅行。

LocalSend 是一个免费、开源的文件传输工具。
只要设备处在可互通的同一本地网络，
照片、视频、文档和文字，都能直接分享。

⇄

跨过设备的边界

Windows 电脑接收 iPhone 照片，安卓手机分享给 Mac。设备不同，也能互传。

02 / 动手试一试

你的第一次互传，
只差三步。

拿起手机，打开电脑，跟着做就好。
↧

先给设备装上它。

发送端和接收端都需要安装。
选择你的系统，前往官方下载。

在官方下载页选择 Windows 安装包，按提示安装。

前往官方下载 ↗只链接官方渠道，放心找对入口。
  1. 01

    都打开，连上同一本地网络

    在两台设备上打开 LocalSend，连接同一个可互通的本地网络，例如家里的 Wi-Fi。

    ↳ 电脑连网线也可以，关键是设备之间能互相通信。
  2. 02

    选文件，再选接收设备

    在发送端选择文件、照片或文字，然后点选附近设备列表中的接收设备。

    ↳ 先对照一下设备名称，避免选错。
  3. 03

    接收端确认，完成！

    在接收设备上按提示确认。传输完成后，检查接收文件夹；保存位置可以在设置中调整。

    ✓ 第一次可以先试传一张照片。

03 / 遇到一点小问题？

先别急，
答案可能在这里。

从最常遇到的问题开始排查。

查看官方故障排查 ↗
LocalSend 需要互联网吗？

核心的本地传输不需要互联网，但两台设备仍需连接到可互通的本地网络。“不用互联网”不等于“不需要网络”。下载和安装应用时通常仍需要互联网。

为什么找不到另一台设备？

先确认双方都打开了 LocalSend，并连接到同一个可互通的本地网络。访客 Wi-Fi 的设备隔离、防火墙和 VPN 都可能影响发现设备。

在你信任的家庭网络中，Windows 可检查网络是否设为“专用”；苹果设备可检查是否允许 LocalSend 访问“本地网络”。

文件安全吗，会先上传到云端吗？

LocalSend 在本地设备之间传输文件，无需先上传到云端。默认使用 HTTPS 加密通信，还可以开启 PIN 验证。接收前，请核对发送方和设备名称。

阅读官方隐私政策 ↗

防火墙需要怎样设置？

按官方说明，允许 LocalSend 进行本地网络通信，默认入站端口为 TCP 和 UDP 53317。优先按系统提示允许该应用在可信网络中通信，具体步骤可参考官方故障排查。
